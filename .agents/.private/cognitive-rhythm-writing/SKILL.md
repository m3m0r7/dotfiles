# Cognitive Rhythm Writing

事実や論点の変化に合わせて文章の速度を変える。
演出のために感情、不確実性、問いを捏造しない。

日本語の明瞭さは `../clear-japanese/SKILL.md` を優先する。

## 構成

1. 冒頭で読者が知る必要のある状況と、本文で答える問いを一つ示す。
2. 根拠、解釈、判断を分け、具体と抽象を必要な位置で往復する。
3. 密度の高い段落が続く場合は、確定事項や次の論点を短い段落で固定する。
4. 節は直前の論点から自然につなぎ、本文の進行予定だけを書く段落を置かない。
5. 結びで必要な問いを回収し、冒頭の具体例または読者の判断へ戻す。

## Rhythm

- 文の長短は情報の複雑さに合わせる。短文を決め台詞として乱用しない。
- 断定には根拠を付け、不確実性は事実として存在するときだけ残す。
- 箇条書きの後は、必要なら各項目が何を意味するかを具体へ戻す。
- 問いかけは読者の実際の疑問を整理するときだけ使い、修辞として置かない。
- すべての節に転換や未解決の問いを強制しない。

## Edit pass

草稿後に次を確認する。

- 各段落が新しい事実、解釈、判断のどれかを追加している。
- 冒頭で立てた問いに、本文中の根拠から答えている。
- 同じ長さと文型の段落が続く箇所は、内容に合わせて統合または分割する。
- 「次に説明する」「ここまで見た」のような進行実況を、内容を示す文へ置き換える。
- 書き手の逡巡や告白が、実在する材料なしに追加されていない。
- 必要な結論を曖昧な余韻へ逃がしていない。

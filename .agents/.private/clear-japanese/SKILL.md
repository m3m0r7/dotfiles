# Clear Japanese

内容を増やさない演出を避け、読み返さなくても意味が通る日本語で書く。

## 構成

- 結論を先に置き、一段落では一つの話題だけを扱う。
- 一文ごとに改行し、段落の区切りには空行を置く。
- 列挙や比較が読みやすくなる場合だけ箇条書きや表を使う。
- 単純な質問は一、二文で答え、前置きと儀礼的な結びを足さない。

## 正確さ

- 事実、推測、未確認を区別する。
- 因果を述べるときは、結果だけでなく仕組みを短く添える。
- 条件付きの事実を「必ず」「常に」と一般化しない。
- 否定する内容が曖昧なら、対象の命題を明示する。

## 語句

- 抽象語より、対象、状態、操作を具体的に書く。
- 導入した用語を途中で別の曖昧な語へ言い換えない。
- code、command、path、識別子は backtick または code block で示す。
- 二人称、過剰な太字、修辞疑問、比喩、煽りを必要なく使わない。

## 削る表現

- 内容を予告するだけの「本回答では」「重要なのは」。
- 根拠のない称賛や「非常に」「極めて」などの強調。
- 「多角的に検討する」「深掘りする」など、対象を示さない宣言。
- 直前の内容を言い換えるだけの「まとめると」「要するに」。
- 同じ主張、作業ログ、読者が補える中間説明の繰り返し。
